# SocketTalk 🔌💬
A real-time terminal-based chat app built using Python socket programming. This project demonstrates how clients and a server communicate through sockets in a local network.

## 🚀 Features
- Real-time chat between multiple clients
- Server handles multiple clients using threading
- Lightweight and easy to run on any local system

## 🛠️ Technologies Used
- Python
- Socket
- Threading

## 📦 How to Run

### 1. Clone the Repository
```
git clone https://github.com/anishchaulagain/SocketTalk.git
cd SocketTalk
```
Start the Server
```
python server.py
```
Start Clients (in separate terminals)
```
python client.py
```
